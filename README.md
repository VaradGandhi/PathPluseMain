PathPulse
An assistive navigation concept that demonstrates obstacle-aware walking guidance for people who are blind or have low vision.

PathPulse is a browser-based prototype built to demonstrate how a navigation assistant could interpret nearby hazards and provide clear spoken guidance, such as when to stop, wait, or continue. The current version uses a simulated street environment so the interaction and decision flow can be explored without physical hardware.
Important: This is a demonstration prototype, not a validated mobility aid. It does not currently read live camera feeds or physical sensors, and it must not be relied on for real-world navigation or personal safety.

Features
- Interactive street simulation with multiple scenarios.
- Simulated obstacles, including pedestrians, bicycles, scooters, poles, and barriers.
- Keyboard and on-screen movement controls.
- Decision logic that generates contextual guidance based on the simulated scene.
- Spoken instructions using the browser's Web Speech API.
- Start, pause, restart, new-hazard, voice toggle, and repeat-guidance controls.
- Safety demonstration mode for showing example guidance behaviour.
- A live status panel showing the nearest simulated obstacle and guidance information.
